# opensource-game
This is an amazing, open source game that **YOU** can commit too!
It's an RPG style 3D voxel game made from JavaScript, where you have full control.
---
## How to commit
First, fork this repo, then go to the page (Usually something like https://github.com/YOUR-NAME/opensource-game/).
Add/edit the chosen files, then click "Contribute".
Create a PR, upload proof of testing, and follow our Rules, it will be reviewed shortly.
Then, once the request is approved you may play the game.
---
### Bugs? 
Create a new issue, then we will review it.
Please state the filename in which you believe the error occurred, and a screenshot of the bug.
---
# Security Vulnerabilities?
We want our project to be safe.
If you have found a security vulnerability, please report it to us.
**Please do NOT use public issues for reporting vulnerabilities.
